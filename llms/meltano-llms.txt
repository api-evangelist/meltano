# Meltano

> Meltano is an open-source, declarative, code-first data integration engine (ELT+) built on the Singer standard. It moves, transforms, and tests data across 600+ pre-built connectors, managed as version-controlled code via a CLI. Backed by GV; originated as a GitLab project.

Meltano is a CLI-first DataOps tool, not an HTTP API. Interaction happens through the `meltano` command-line interface and the declarative `meltano.yml` project file. Custom connectors are built with the Meltano Singer SDK.

## Products
- [Meltano Open](https://docs.meltano.com/): self-hosted, open-source data integration foundation
- [Meltano Hub](https://hub.meltano.com/): catalog of 600+ extractors, loaders, and utilities
- [Meltano SDK](https://sdk.meltano.com/en/latest/): framework for building Singer taps and targets
